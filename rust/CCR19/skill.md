# Skill Name

CCR18 Software Requirements Generator

# Description

This skill converts customer business requirements into software requirements for a beginner-level Rust programming project.

The skill identifies the program purpose, inputs, outputs, variables, functional requirements, non-functional requirements, and project constraints.

The skill must not add features that were not requested by the customer.

# Instructions

1. Read the customer change request.
2. Identify the business problem the customer wants solved.
3. Identify all required inputs.
4. Identify all required outputs.
5. Identify all data that must be stored.
6. Identify all variables needed by the program.
7. Create functional requirements.
8. Create non-functional requirements.
9. Create program constraints.
10. Keep all requirements within the scope of the customer request.
11. Use beginner-friendly language.
12. Use only concepts that have been taught in the course.

# Procedure

Step 1:
Read the customer requirements and business background.

Step 2:
Determine the purpose of the software.

Step 3:
Identify the information the user must enter.

Step 4:
Identify the information the program must display.

Step 5:
Identify the variables required by the program.

Step 6:
Create functional requirements.

Step 7:
Create non-functional requirements.

Step 8:
List any constraints or out-of-scope features.

Step 9:
Create a final software requirements document.

# Example

Customer Requirement:

The employee should enter customer names into a waiting list until there are no more customers waiting.

Software Requirements:

Program Purpose:
Create and display a restaurant waiting list.

Input Requirements:
- Customer Name
- Add Another Customer (Y/N)

Output Requirements:
- Waiting List
- Total Customers
- First Customer
- Last Customer

Variables:
- waiting_list
- customer_name
- answer

Functional Requirements:
- Allow entry of customer names.
- Continue accepting names until employee enters N.
- Display all customers.
- Display total customers.
- Display first customer.
- Display last customer.

Non-Functional Requirements:
- Command-line application.
- Easy to read output.
- Beginner-level Rust implementation.

Constraints:
- No database.
- No file storage.
- No GUI.
- No reservation system.
- No wait-time estimation.

# Resources

Rust Concepts Allowed:

- Variables
- Strings
- User Input
- Vectors (Vec)
- Loop
- While Loop
- If
- Else
- Basic Formatted Output

Purpose:

Convert customer requirements into software requirements that can be implemented using beginner-level Rust programming concepts.
