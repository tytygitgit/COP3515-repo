# Equipment Rental System

## What Changed in This Client Change Request

- Created a Cargo project named equipment_rental.
- Created three equipment records.
- Added Equipment ID, Equipment Name, Category, and Availability fields.
- Displayed equipment information in a formatted inventory report.
- Displayed availability as user-friendly Yes or No values.

## How I Tested the Application

1. Ran cargo build to verify the project compiled successfully.
2. Ran cargo run to verify the program executed successfully.
3. Verified that the title and version number were displayed.
4. Verified that three equipment records were displayed.
5. Verified that each record displayed an Equipment ID, Equipment Name, Category, and Availability value.
6. Verified that availability was displayed as Yes or No.
